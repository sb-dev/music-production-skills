# Concrete Halo

**Level 2 — boom-bap hip-hop — selection and preservation**

Compare genuinely different beat/hook directions, combine the best compatible decisions, and preserve them through a refined demo.

## Prompt

```text
Use music-compose, music-produce and music-evaluate to develop a boom-bap hip-hop demo called "Concrete Halo" through explicit alternatives and selection.

Requirements:
- Genre: boom-bap / sample-led hip-hop
- Tempo: 90 BPM
- Tone: dusty, tense, understated
- Core palette: chopped soul-like harmonic texture, dry drums, sub or electric bass, sparse melodic accent
- Vocal role: leave clear space for a rap verse; a short non-lyrical or minimal hook is acceptable

Create three materially different draft directions:
- one built around a chopped harmonic phrase
- one built around a bass-led motif
- one built around a drum-and-vocal-space concept

Workflow:
- State what musical question each draft is testing
- Keep drafts cheap: MIDI, short loops or low-cost audio sections are sufficient
- Compare groove, hook potential, space for the vocal and production identity
- Select components independently when justified; the best drums and the best musical motif do not need to come from the same draft
- Record which decisions are selected, approved or locked
- Build a refined 60–90 second demo from the selected components
- Verify that refinement preserves approved decisions

What to optimise for:
- pocket and swing
- a recognisable central sample/motif identity
- enough negative space for rap delivery
- meaningful contrast between the three drafts
- traceable component-level selection
```

## What this example tests

- materially distinct draft set
- component-level selection
- decisionState separate from workflowState
- preservation through refinement
