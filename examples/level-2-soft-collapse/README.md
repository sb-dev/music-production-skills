# Soft Collapse

**Level 2 — dream pop / shoegaze — selection and preservation**

Explore contrasting chorus treatments without losing the underlying song, then lock the chosen musical identity before production.

## Prompt

```text
Use music-compose, music-produce and music-evaluate to develop a dream-pop / shoegaze demo called "Soft Collapse".

Start from this fixed song idea:
- Tempo: 82 BPM
- Meter: 4/4
- Mood: suspended, bittersweet, slowly widening
- Verse harmony: keep a restrained four-chord cycle
- Vocal: soft lead melody with one short repeated chorus line

Create three chorus arrangements that keep the same core lyric idea but differ materially:
- A: vocal-forward, minimal guitar wash
- B: rhythm-forward with a pulsing bass and tighter drums
- C: wide guitar/synth wall with the vocal floating above it

Workflow:
- Keep the verse stable while comparing chorus directions
- Evaluate which chorus best supports the lyric and energy arc
- Select the strongest vocal melody independently from the strongest arrangement if necessary
- Move chosen decisions through selected → approved → locked only when justified
- Produce a refined demo that preserves locked melody, lyric and harmony
- Run preservation evaluation after refinement

What to optimise for:
- contrast between intimate verse and expanded chorus
- vocal intelligibility inside dense texture
- emotional lift without simply making everything louder
- preservation of the chosen topline and harmonic identity
- evidence for why the selected components won
```

## What this example tests

- same song, materially different arrangement drafts
- selection vs approval vs locking
- preservation under denser production
