# Low Orbit

**Level 3 — melodic techno — full production**

Take an approved instrumental composition through demo, model-backed production, targeted refinement, QC and final evaluation.

## Prompt

```text
Use music-compose, music-produce and music-evaluate to create a finished melodic-techno instrumental called "Low Orbit".

Requirements:
- Duration: 2:30–3:00
- Tempo: 124 BPM
- Meter: 4/4
- Tone: hypnotic, restrained, late-night rather than euphoric
- Palette: deep kick, sub/bass pulse, muted percussion, one evolving synth motif, atmospheric texture
- Structure: intro → groove → first development → breakdown → final return → controlled outro
- Vocals: none

Workflow:
- Establish and approve the composition and arrangement before final production
- Create a demo that proves motif, groove and energy arc
- Evaluate the demo; fix composition/arrangement failures upstream before committing to final production
- Use Replicate model discovery/comparison for generative audio rather than a hard-coded model
- Produce the full track
- Refine only the smallest failing section where possible
- Run deterministic audio inspection/QC and final music evaluation
- Produce the required delivery master without inventing native stems if the execution path cannot supply them

What to optimise for:
- low-end clarity
- gradual development without excessive new material
- breakdown-to-return impact
- motif continuity
- professional structural pacing
- a final result that still sounds like the approved demo
```

## What this example tests

- complete vertical production loop
- Replicate-backed execution
- targeted refinement before restart
- technical QC + final evaluation
