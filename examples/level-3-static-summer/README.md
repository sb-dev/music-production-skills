# Static Summer

**Level 3 — indie rock / dream rock — full production**

Produce a band-oriented song where arrangement, performance feel and sonic density must stay coherent from demo to master.

## Prompt

```text
Use music-compose, music-produce and music-evaluate to create a finished indie-rock / dream-rock song called "Static Summer".

Requirements:
- Duration: about 2:45
- Tempo: 112 BPM
- Meter: 4/4
- Palette: live-feel drums, electric bass, two contrasting guitar roles, one lead vocal
- Mood: restless, bright on the surface, slightly worn underneath
- Structure: short intro → verse → chorus → verse → chorus → bridge → final chorus/outro
- Production: energetic but not hyper-compressed; preserve some band-like dynamics

Workflow:
- Approve the song and arrangement before full production
- Use the demo to establish which guitar plays rhythm, which carries texture, and when each should drop out
- Preserve the approved vocal melody and section order through production
- Generate/realise the final track using the current best compatible Replicate path
- Evaluate whether dense guitars mask the vocal or bass rather than treating density as automatically better
- Make bounded corrections to the responsible section/production layer
- Run technical QC and final evaluation

What to optimise for:
- believable band roles
- chorus energy without constant full-density guitars
- vocal readability
- dynamic contrast
- continuity between demo decisions and final production
```

## What this example tests

- band-oriented full production
- arrangement roles carried into production
- creative density evaluation + bounded correction
